# S0 ルールノート

更新日: 2026-09-05。実装開始依頼に基づく開発用採用値。公開条件の承認や権利許諾の取得を示すものではない。

## 開発前提

- 方針A（完全オリジナル・架空企業化）で実装。参考名・実在ロゴ・実在製品の画像はアプリへ取り込まない。公開名称・素材の確認は公開前に別途行う。
- 対象は1960年1月〜2010年12月。1か月4週・1年48週。週数を唯一の時間軸とし、表示年月はそこから導出する。
- MVPはPC優先。製品版はスマホ・タブレットも対象。無料・課金なし、ランキング・キャリア実績は製品版必須範囲外。
- 基本プレイはログイン不要。IndexedDB保存はS5、任意クラウド同期はS10。S0のD1は接続確認専用。
- S0画面の週送りは暦表示の検証。会計・決算・シナリオは進行しない。最終年代での停止はゲームエンジン実装時に加える。

## S1以降の計算仕様

金額はゲーム内の「万円」を整数で保持。最大絶対値は1兆単位、中間計算も安全整数を確認し上限超過を拒否。率は整数の万分率、費用の端数は取引単位で切り捨てる。

週更新順は解禁・イベント、コマンド確定、研究・開発、生産、販売、記帳、ブランド等の更新、月末・年末集計と勝敗判定、ログ更新。コマンドは適用週と連番を持ち再実行を拒否。乱数はシードと内部状態を保存し、画面表示から消費しない。

研究費・固定人件費は週ごとの費用。生産費は在庫資産に計上し、販売時に移動平均原価で売上原価へ振り替える。設備は資産、減価償却は月末。月次は4週、年次は48週の境界で一度だけ締める。財務3表は同じ複式台帳から導出する。

必須支払いに現金が足りない場合、その週の更新全体を確定せず、資金不足を表示して月送りを中断する。借入・支出変更後に同じ週を再試行できる。解決せず進行する選択で猶予週を1消費し、4週分で敗北。再表示や連続クリックだけでは猶予を消費しない。二重計上・警告後の復帰・期限超過をS1/S3で検証する。

## SC01の初期案（未実装）

「暮らしの電化」、1960年初〜1964年末の240週。初期現金・資本金は各10,000万円、借入0、ブランド10/100。基本の冷却・洗浄・白黒映像技術を保有し、冷蔵庫・洗濯機・テレビを設計可能にする。研究は省電力の改良から案内する。

期限時点で累計売上30,000万円以上、累計利益3,000万円以上、ブランド30以上をすべて満たせば成功。資金不足の猶予切れは即敗北、期限未達は期限敗北。破産判定を成功判定より優先。成立性はS4の成功・失敗試走で確認する。

初回導線は研究投資→冷蔵庫設計→開発→生産→価格・直営販路→発売→初回売上→決算。技術・原価・研究費の具体的な定義はS2/S3で追加する。
