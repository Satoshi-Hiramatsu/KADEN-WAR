# KADEN WAR — 家電戦争

日本の家電産業の変遷をモチーフにした、ブラウザ向け経営シミュレーションゲームの開発プロジェクトです。プレイヤーは架空の家電メーカーの社長となり、製品開発・生産・販売・財務・組織を動かして業界の覇権を目指します。

**コミット済みの最新版: V0.0.3（S0のローカル基盤）。作業ツリーには未コミットのS1〜S3ローカルデモが入っています。製品版v1.0の完成ではありません。**

ローカル環境で、入門シナリオSC01「暮らしの電化」を実際に操作できます。研究予算の設定 → 製品設計 → 開発 → 生産 → 価格・販路 → 発売 → 週次の売上 → 月次・年次決算までが1つの会社状態でつながり、5年（240週）後に目標達成か未達かが判定されます。

まだ無いもの: 保存・再開（S5）、競合AIの意思決定と年代イベント（S4）、規格戦争・特許・人事（S6以降）、演出とドット絵素材（S9）、クラウド保存（S10）、公開URL。S0の実環境配信確認も残っています。

## 作りたいゲーム

中心となる体験は「研究投資 → 製品設計 → 開発 → 生産 → 発売 → 市場の反応 → 次の改良」。性能の高さだけでなく、価格・投入時期・品質・販路・資金繰りの組み合わせが結果を左右する経営を描きます。

- 白物家電・映像・音響・パソコンなど、年代に応じた製品開発。
- 直営店・系列店・量販店・ネット販売へと変わる販売戦略。
- 規格・互換性・提携・特許をめぐる競争。
- 月次会議・年度計画・決算を通じた会社運営。
- レトロなドット調グラフィックスと、読みやすい操作画面の組み合わせ。

時代は1960年〜2010年末を仮の範囲としています。シナリオ6本、フリープレイ、チュートリアル、製品図鑑・開発史を製品版v1.0の対象として計画しています。リポジトリのコミット版と製品版の目標は別のものです。

## リポジトリの取得と確認

```sh
git clone git@github.com:Satoshi-Hiramatsu/KADEN-WAR.git
cd KADEN-WAR
```

Node.js 24系で `npm ci`、`npm run dev` を実行すると `http://127.0.0.1:5173` でデモを開けます。タイトルの「この条件で始める」からSC01を開始できます。ゲーム本体はブラウザだけで動くため、APIとデータベースは必須ではありません。接続確認まで試す場合は別ターミナルで `npm run api:types`、`npm run db:migrate`、`npm run api:dev` を実行します。検証は `npm run check`。

### デモの進め方

1. **研究所**：研究予算（万円/週）を決め、研究課題を選ぶ。分類・部品・品質・製品名を選ぶと性能・原価・開発期間・開発費が表示されるので、そのまま開発を始める。
2. **販売本部**：系列店か直営店を開く。販路がないと発売できない。
3. **社長室の「1か月進める」**：開発が終わるまで週を進める。開発費は毎週分割で支払われる。
4. **工場**：完成した製品の週あたり生産量を決める。生産費は在庫の資産になり、売れた分だけ移動平均原価で売上原価へ振り替わる。
5. **販売本部**：価格を決めて「発売する」。市場の需要を、性能・価格・ブランド・販路の到達力で競合3社と取り合う。
6. **経理部**：損益計算書・貸借対照表・キャッシュフロー・仕訳・借入を確認する。4週ごとに月次決算、48週ごとに年次決算が出る。
7. 必須の支払いに現金が足りない週は、週送りが中断して資金不足の案内が出ます。借入や支出見直しの後に同じ週をやり直せます。そのまま進めると猶予を1週使い、4週続くと敗北します。

[開発・検証手順](docs/development.md)にAPIと配信の残作業、[ルールノート](docs/rule-note.md)に採用した計算仕様と未決事項を記載しています。

## グラフィックスを追加する場合

Codexでは `$kaden-war-graphics` を指定するか、専用スキルを読み込んで制作します。承認済み顔原画を実際に画像参照として使い、描画密度・暖色系の配色・輪郭・陰影を揃えます。既存人物の差分では顔立ち・髪型・服装を維持します。

原画を上書きせず、版を付けて保存し、生成プロンプト・参照元・確認結果・承認状態を台帳に残します。顔原画以外の製品・施設素材は今後の制作対象です。
